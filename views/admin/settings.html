Comment obtenir vos identifiants Brevo ?

  1. Connectez-vous à votre compte Brevo
  2. Allez dans Paramètres (icône engrenage)
  3. Cliquez sur SMTP & API
  4. Générez une nouvelle clé API si nécessaire
  5. Copiez la clé et collez-la ci-dessus

Note : L'identifiant SMTP est généralement votre adresse email Brevo.
